SRP-3 Formalisation

ProVerif Security protocol

Secure Remote Password (SRP-3) is an authentication and session-key establishment protocol designed to resist dictionary attacks. This project provides a ProVerif model and verifies that, under this model, the protocol satisfies the intended security properties.

FAT32 File System Emulator

Java JavaFX File system

A FAT32 file system emulator implemented in Java, with both command-line and graphical interfaces. The shell supports commands such as ls, cd, cat, and echo. The JavaFX interface provides a file explorer, a disk fragmentation visualizer, and tools for file management and disk formatting.

JPEG Decoder

C++ DCT Compression

A JPEG decoder that converts compressed JPEG images into raw pixel data. It implements the main steps of the baseline JPEG decoding pipeline: Huffman decoding, dequantization, inverse discrete cosine transform (IDCT), and conversion from YCbCr to RGB.
